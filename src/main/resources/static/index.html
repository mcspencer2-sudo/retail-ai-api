CSV Upload Rules

Follow these rules to avoid row-level import errors.

Required Columns
  • rfid
  • item_name
  • category
  • price
  • stock_quantity
Allowed Categories
  • Tops
  • Bottoms
  • Shoes
  • Outerwear
Valid Values
  • Price must be numeric, like 80.0
  • Stock must be a whole number, like 12
  • Active and available must be TRUE or FALSE
Example bad row: price = INVALID will return a row-level error like: Row 4 — Invalid price value: INVALID
